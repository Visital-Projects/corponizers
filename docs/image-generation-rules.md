# Image Generation Rules

• Never overwrite approved images.
• Check manifest before generation.
• Generate only missing assets.
• Preserve visual consistency.
• Preserve employee identities.
• Maintain identical lighting.
• Maintain identical color grading.
• Maintain identical camera angle.
• Maintain identical photography style.
• Save only WebP.
• Use descriptive filenames.
• Every generated image must be registered.
• Every approved image becomes immutable.
• Every image references employee IDs.
• Every image references its page and section.
• Duplicate scenes are not allowed.
• Camera angles should vary.
• Wardrobe should vary.
• Expressions should vary.
• Composition should vary.
• Identity must remain identical.
