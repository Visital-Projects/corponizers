# Master Scene Catalog

Every generated image must represent a unique business scenario.
Never repeat the same composition across multiple pages.
No duplicated handshakes.
No duplicated boardrooms.
No duplicated laptop discussions.
No duplicated interview angles.
The website should feel like one continuous corporate photoshoot.

## Composition Rules
* Never reuse identical composition.
* Never reuse identical camera angle.
* Never reuse identical lighting direction.
* Never reuse identical table layout.
* Never reuse identical background.
* Never reuse identical employee placement.
* Alternate: Close-up, Medium, Wide, Over-the-shoulder, Walking, Standing, Seated, Presentation, Discussion.

## Identity Rules
* Employees must remain identical.
* Faces must never drift.
* Hair must never change.
* Facial hair must never change.
* Skin tone must never change.
* Age must never change.
* Business attire may vary naturally.

## Photography Style
* Premium Fortune 500 annual report
* Natural daylight
* Modern Indian corporate offices
* Glass meeting rooms
* Minimalistic interiors
* Shallow depth of field
* 85mm corporate portrait style
* Soft neutral grading
* Professional documentary photography
